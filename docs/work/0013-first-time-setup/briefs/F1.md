## What to build

1. A new module `src\dsh\bundle.js` with a small interface: `state(deps)` returns the object of the contract; `install(deps)` does what the contract says and returns `{ok, bundle, message, log}`. Everything that touches the outside world is a dependency with a real default: the Harness home, the Harness program folder, the DSHProxy root, the list of running processes, and the function that runs the command. Tests inject them.
2. `dshproxy dsh bundle status [--json]` and `dshproxy dsh bundle install [--json]` in `src\cli.js`, with two help lines. Without `--json`, `status` prints one or two plain sentences a person can act on.
3. Rules that matter:
   - **Read-only means read-only.** `state` writes nothing, anywhere.
   - **DSHProxy's own code never writes into a Harness profile's `package.json`, `node_modules` or lock file.** Only Harness's command does.
   - **The command is run at most once per `install`, never retried.** A timeout (120 s) ends the child and its children, and the result is whatever a fresh look at the profile says, with a message that the command did not finish.
   - **Refuse rather than guess.** `install` runs nothing when Harness is running, when the profile does not exist (Harness never opened), when Harness is not found, when the plugin is `switched-off`, or when the folder path is not safe to pass.
   - **The folder path goes through `cmd.exe`** (a `.cmd` file cannot be started without it). A path containing any of `% " ^ & | < > !` or a line break is refused with a reason; do not try to escape it. Prove with a test that a folder named like `a & echo INJECTED` never reaches a shell.
   - **Environment of the child:** every variable whose name starts with `DSH_` is removed, then `DSH_HOME` is set to the Harness home in use; `ELECTRON_RUN_AS_NODE` is removed (the `.cmd` sets it itself).
   - **Harness is running** when a process `DeepSeek Harness.exe` whose program path is inside the Harness folder exists. A process list that cannot be read counts as running. The default reader may use `powershell.exe` with `Get-CimInstance Win32_Process`; keep it to one call with a timeout.
   - `linkedTo` and `folder` are compared as resolved absolute paths, case-insensitively, with either slash.
   - A profile `package.json` or `cordis.patch.yml` that cannot be parsed: `state` does not throw; it reports `canInstall: false` with the reason.
   - `reason` and `message` are plain sentences for the person at the app: what is so, and what to do. No stack traces, no raw command output beyond its last non-empty line.
