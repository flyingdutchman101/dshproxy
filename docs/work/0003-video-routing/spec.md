# Video routing in DSHProxy

Add a `dshproxy video` command to the existing application. V1 supports the verified text-only, 16:9, five-second benchmark presets (Seedance 2.0/2.5 standard and Wan 3.0 standard at 720p, MiniMax H3 at 768p). A quote is offline, dated, itemizes route and currency, and cannot start a job. Use pinned VideoRouter hosts, KovAPI prepaid, or explicitly selected Callirra Pro at full utilization. A monthly effective cost is not a cash price or authority to subscribe. Krea uses the external client's OAuth session: produce a preflight-only handoff, not API dollars, and never read its tokens.

Acceptance: CLI quotes match verified benchmarks; unknown model/route combinations fail closed. Submitting requires an explicit route, prompt, acknowledgement, sufficient per-clip budget in the provider’s billing unit (USD, or credits for Callirra), and provider-scoped credential; one POST only, no failover/retries, including ambiguous errors. Status reads the original provider job without generating. Do not expose raw upstream error bodies or credentials. No installation, desktop release, daemon changes, credential writes, purchases or live paid tests. Use native Node tests with mocked HTTP.

Approved extension (2026-11-22): the manual handoff remains offline. For an explicitly requested live workspace quote, signed-in submit or poll, use the separate Windows OAuth companion chosen by the user. See `oauth-release.md` and decision 0003. DSHProxy never accepts a workspace token in its own arguments, environment or helper response. Only explicit helper login/logout may manage an actual credential, and neither is authorized during mock verification.
