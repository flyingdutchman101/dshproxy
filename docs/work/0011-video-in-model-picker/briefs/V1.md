## What to build

1. The helper's four actions against the live interface: `quote`, `submit`, `status`, and a new `balance`.
   - Tool `generate_video` (not `generate`); model ids without the `video/` prefix; `get_job` takes `jobId`; job statuses and result shape as recorded; `get_balance` for the balance.
   - Protocol version: accept what the server returns when it is `2025-06-18` or `2025-11-25`, use it in the header afterwards, refuse anything else.
   - A request carries an optional `resolution`. Without one, the model's present default applies (720p for the two Seedance models and Wan 3.0; none for MiniMax H3, whose Krea endpoint has no resolution setting and is a fixed tier). 480p, 720p and 1080p must work for the three models that have the setting. Asking a resolution of MiniMax H3 is refused.
   - What is sent to `generate_video` is exactly `{model, input: {prompt, duration: 5, aspect_ratio: "16:9"[, resolution]}, preflight}`. Nothing else, ever. Note that `alibaba/wan-3.0` defaults `aspect_ratio` to `adaptive`, so the field must always be sent.
2. Schema checking, re-drawn (see the ledger's rulings): refuse drift in what DSHProxy sends (criterion A6); do not refuse keywords, annotations, tools or output schemas the helper does not use. The server's acceptance of the free preflight is the authority on the input; a submit only ever sends the input its own preflight just accepted in the same process.
3. Keep every safety property the helper has: one paid request per process, never retried; a preflight must be a plain preflight (`mode: preflight`, no job field) or the helper refuses; any failure after the paid request is sent is "outcome unknown" (`KREA_UNCERTAIN`), never "refused"; the cap is compared with the quote; no token in output. Compute units are fractional numbers: do not round them and do not require integers.
4. CLI: `dshproxy video quote MODEL krea --prompt "..." [--resolution R]`, `video submit MODEL krea --max-units N --confirm-charge [--resolution R] "PROMPT"`, `video status MODEL krea JOB_ID`, and new `dshproxy video balance krea`. Existing invocations without `--resolution` behave as the text above says. Keep the output shape of existing commands: the bundle `integrations\dsh-video\runner.cjs` requires `src\video\command.js` by path and parses its output (code map D2). Run the bundle's tests.
5. The model id map exists twice today (`mcp.js` and `krea-preset.js`). Leave one.

Out of this slice: Flux 3, the API routes, the catalog, settings, sign-in and renewal (`src\krea-helper\oauth.js` belongs to another implementer working right now in another worktree: do not edit it), the desktop app, the gateway.
